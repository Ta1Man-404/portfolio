## Структура (лендинг, фрейм «Desktop - 1», ~1920 px; canvas 2440×4942 с боковыми панелями состояний)

1. **Header** — логотип (оливковая иконка + «Пицца»), меню: Главная / Пицца / Почему мы,
   CTA-кнопка «Заказать». В файле есть состояния кнопки: Default / Hover / Pressed.
2. **Hero** — тёмное фото кусков пиццы с базиликом на всю ширину (снимок сверху),
   H1 «Пицца из печи», подзаголовок про печь и «вкус настоящей Италии», CTA «Заказать».
3. **Преимущества** — H2 «Почему наша пицца такая вкусная?» + 3 пункта с иконками:
   - Итальянская печь — «Выпекает хрустящую снаружи и сочную внутри пиццу»
   - Оливковое масло — «Делает тесто мягче и придаёт ему приятный аромат»
   - Идеальный сыр — «Тянется за каждым кусочком и тает во [рту]»
   Иконки: oven, olive-oil, cheese (оливковые).
4. **Выбор пиццы** — H2 + **глобальный переключатель размера** (табы 24 / 30 / 36 см,
   состояние Selected) + сетка 3×2 из 6 круглых фото пицц:
   Вегетарианская, Курица и грибы, Ветчина и грибы, Маргарита, Пепперони, Салями.
   В карточке: название, иконки ингредиентов (bell-pepper, mushroom, tomato, zucchini,
   cheese, chilli, sausage, olives), цена, оливковая кнопка «Заказать».
   Цены в данных: 360 / 390 / 420 / 510 (₽) — зависят от размера.
   Плейсхолдер «NN см» — в карточке подставляется выбранный размер.
   Слои «Pizza top» / «Pizza bottom» — фото пиццы разделено на основу и топпинг.
5. **Форма** — H2 «Заказать пиццу», текст «Заранее забронируйте столик и сделайте заказ,
   чтобы к вашему приходу пицца была готова.», поле «Телефон», кнопка «Заказать»,
   справа крупное фото куска пиццы с базиликом.
6. **Footer** — логотип слева, «Все права защищены» справа.

## Палитра (по превью, точные значения — на этапе вёрстки через WebBridge)

- Фон: #1F1F1F (кроме hero — там фото с затемнением)
- Текст: белый / off-white
- Акцент: светлый оливковый (fills ≈ #C7CDA6, тёмный вариант ≈ #848D6F / #6B725B)
- Кнопки: оливковая заливка + тёмный текст

## Шрифты

- **Nunito** Regular + Bold (всё, включая заголовки). Кириллица есть ✓
- Noto Sans Symbols2 — фолбэк для отдельного глифа (иконка-символ)

## Ассеты (16 PNG, извлечены в assets-source/)

- Hero-фото: 512 + 4096 (тёмное, куски пиццы с базиликом)
- Кусок пиццы для формы: 450 + 3600
- 6 пицц × 2 размера (512 и 4096, RGBA на прозрачности) — маргарита, пепперони,
  салями, ветчина, вегетарианская, курица/грибы (точный маппинг — на вёрстке)
- Все большие фото ~20 МБ — обязательно в WebP, srcset по размерам

## Огрехи макета (учесть)

- Заголовки и кнопки — всё одним шрифтом Nunito: визуально плоско, нет иерархии
  «характера» (у прошлых макетов был акцентный рукописный/антиква)
- «Идеальный сыр — тает во…» — текст обрывается («тает во»), нужно «тает во рту»
- Глобальный свитчер размера в макете статичен — неочевидно, что цены зависят от него
- Нет состояния формы (успех/ошибка), нет мобильной версии — как всегда, проектируем сами

## КОНЦЕПЦИЯ АПГРЕЙДА: «Жар печи»

Настроение: тёмная пиццерия у живого огня. Фон #1F1F1F остаётся, оливковый — основной
акцент (фирменный знак макета), плюс вводим **второй, тёплый акцент — янтарно-огненный**
(≈ #E8912D / градиент углей) точечно: свечения, hover-состояния, микродетали «огня».
Тёплый свет против холодного оливкового — пицца «из печи», а не из холодильника.

### Типографика
- Заголовки добавляем характера: оставить Nunito Bold, но с tightened tracking,
  каскадным появлением по словам; акцент-строки («такая вкусная?») — оливковым,
  как в макете.
- Цены и размеры — табличные цифры (font-variant-numeric: tabular-nums).

### Hero
- Полноэкранное фото + медленный Ken Burns (масштаб 1.0→1.06), затемнение-градиент снизу.
- Поднимающиеся **искры/угли** (canvas-частицы, ~20 шт., янтарные, off при reduced-motion)
  + лёгкое тепловое мерцание-виньетка по краям.
- Заголовок — каскад по словам, CTA — с «огненным» свечением при hover.

### Преимущества
- Иконки рисуются stroke-анимацией (SVG draw-on) при скролле, stagger.
- Карточки — лёгкий подъём + тёплая подсветка кромки при hover.

### Меню (главная фишка)
- **Рабочий свитчер размера 24/30/36 см**: цены в карточках пересчитываются с
  анимацией (flip/слайд цифр), а сами пиццы **плавно растут/уменьшаются** в масштабе —
  размер видно, а не только написан. Подстановка «NN см» в карточки.
- Пиццы на прозрачности — медленное вращение при hover (или tilt), тень-подложка.
- Иконки ингредиентов с тултипами (доступные: aria-label).
- Reveal сетки — stagger через ScrollTrigger.
- Кнопка «Заказать» в карточке → сохраняет выбор (пицца + размер) → форма подхватывает
  чипом «Ваш выбор: Пепперони, 30 см — 450 ₽» (паттерн из макетов 1–3).

### Форма
- Маска +7 (___) ___-__-__, живая валидация через textContent, экран успеха с
  выбранной пиццей/размером. Данные не уходят в сеть (preventDefault).
- Кусок пиццы справа — лёгкий параллакс за курсором + «дыхание».

### Общее
- Шапка: fixed, стекло при скролле (как в 01–03), бургер < 720 px.
- GSAP + ScrollTrigger, IntersectionObserver, prefers-reduced-motion фолбэки везде.
- Шрифт Nunito variable woff2 локально (кириллица), font-display: swap.
- Ассеты → WebP (512 для карточек, 1024/1600 для hero/слайса), lazyload ниже сгиба.
- Чеклисты по PORTFOLIO-STANDARD.md: семантика, SEO (OG, favicon, robots), CSP-мета,
  без innerHTML для пользовательского ввода.
